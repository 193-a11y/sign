# 휴가 신청 (Netlify, 간단 버전)

근무자: **로그인 없음.** 링크 접속 → 근무지(학교) 선택, 성함, 연락처, 직종 → 휴가 종류·기간 → 서명 → 제출.
관리자: 우상단 "관리자 로그인"(또는 `/admin`)으로 로그인해야 승인·반려·PDF·CSV 사용 가능.

## 구조
- `public/` 화면 (`index.html` 신청, `admin.html` 관리자)
- `netlify/functions/api.mjs` API (`/api/*`)
- `netlify/database/migrations/` DB 테이블 (배포 시 자동 적용, 파일 2개)
- `netlify.toml` 설정

## 배포 체크리스트
1. 저장소 맨 위에 `netlify.toml`, `package.json`, `public/`, `netlify/` 가 바로 보이게 올린다.
2. Netlify 사이트에서 Netlify Database 활성화.
3. 환경변수: `ADMIN_PASSWORD`(12자 이상), `SESSION_SECRET`(40자 이상 임의 문자열), 선택 `DUTY_MULT`(기본 2). ※ PHONE_KEY는 더 이상 필요 없음.
4. 환경변수 저장 후 Trigger deploy 한 번 더.
5. `/admin` → `admin` / ADMIN_PASSWORD 로그인 → 비밀번호 변경 → 관리자 계정 생성(최대 10개).
6. **"근무지 추가"로 학교 목록 등록** (엑셀 A열 또는 붙여넣기). 목록이 비어 있으면 근무자가 신청할 수 없음.
7. 시험 신청 1건 → 승인 → PDF 확인 → 시험 건 삭제.

## 운영 규칙
- 근무자는 목록에 있는 근무지만 선택 가능 → 학교 이름 표기를 통일해서 올릴 것.
- 근무자는 철회·취소를 직접 못 함. 잘못 들어온 건은 관리자가 "삭제" 또는 "반려/취소 처리".
- 당직경비: 격일 근무 기준. 첫 출근일~마지막 퇴근일을 고르면 이틀 간격 출근일을 자동 계산(출근 1회 = 2일 차감), 토·일·공휴일 포함, 반차 불가 / 시설관리·미화: 평일만.
- 같은 이름+연락처로 기간이 겹치면 접수 거부. IP당 시간당 60건, 연락처당 10건 제한.
- 계약 종료 학교는 "관리"에서 숨기기(기존 신청 기록은 유지).

## 개인정보 주의
- 연락처·서명은 DB에 그대로 저장되며 관리자만 조회 가능. 관리자 계정을 필요한 사람만 갖게 하고, 퇴직 시 즉시 정지.
- 로그인이 없어 링크를 아는 사람은 누구나 신청 가능. 링크는 근무자에게만 공유하고, 관리자가 연락처·서명을 확인하고 승인하는 구조(승인 전에는 효력 없음).
- 이전 버전의 근무자 명단/로그인 테이블(employees)은 DB에 남아 있을 수 있으나 사용하지 않음.
